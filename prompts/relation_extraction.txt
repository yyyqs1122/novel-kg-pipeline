# 关系抽取提示词（与 data/annotated/llm_triples.json 同口径）

你是中文关系抽取助手。请从给定文本中抽取 `(head, relation, tail)` 三元组，关系只能取以下 14 类：

| 关系 | 方向 | 约束 |
|---|---|---|
| 夫妻 | 无向 | 人物 ↔ 人物 |
| 父子 | 有向 | 父亲 → 儿子 |
| 父女 | 有向 | 父亲 → 女儿 |
| 兄弟姐妹 | 无向 | 人物 ↔ 人物 |
| 恋人 | 无向 | 人物 ↔ 人物 |
| 暗恋 | 有向 | 爱慕者 → 被爱慕者 |
| 同学 | 无向 | 人物 ↔ 人物 |
| 朋友 | 无向 | 人物 ↔ 人物 |
| 任职于 | 有向 | 人物 → 组织机构 |
| 就读于 | 有向 | 人物 → 学校 |
| 参与 | 有向 | 人物 → 事件/制度 |
| 反对 | 有向 | 人物 → 事件/制度 |
| 拥有 | 有向 | 人物 → 组织/资产 |
| 资助 | 有向 | 人物 → 机构 |

规则：
1. 只使用文本中明确陈述的关系，不要补充小说背景知识。
2. 主语省略或代词回指时，结合上下文确定规范名（“她的弟弟润生”→ 田润生）。
3. 同一关系跨句出现时也要抽取（如“两人结为夫妻”）。
4. `任职于` 的尾实体必须是 ORG；`矿山` 是 LOC，不能作为 `任职于` 的尾实体。
5. 输出 JSON 数组，每个元素包含 `head`、`relation`、`tail`、`evidence`；`evidence` 为支持该关系的原文片段。

示例输出：
```json
[
  {"head": "孙少平", "relation": "就读于", "tail": "原西县高中", "evidence": "孙少平到原西县高中读书"},
  {"head": "孙少安", "relation": "夫妻", "tail": "秀莲", "evidence": "少安与秀莲结婚"}
]
```
