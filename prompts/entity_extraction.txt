# 实体抽取提示词（与 data/annotated/llm_entities.json 同口径）

你是中文信息抽取助手。请从给定文本中抽取实体，严格按以下 5 类标注：

- PER 人物：姓名、称谓（如“孙少平”“田晓霞”）
- LOC 地点：地理区域、矿区等（如“山西”“矿山”）
- ORG 组织机构：学校、机关、企业、事业单位、基层生产组织（如“原西县高中”“县革委”“生产队”“煤矿”）
- TIME 时间：绝对时间、相对时间、年龄（如“1975年初”“两年后”“27岁”）
- EVENT 事件/制度/运动：事件、制度、运动、会议、采访、灾害（如“责任制”“农业学大寨”“十一届三中全会”“旱灾”）

规则：
1. 只抽取文本中明确出现的实体，不要补充小说背景知识。
2. 实体边界取最长匹配；不要把“孙少平”拆成“孙少/平”。
3. 同一实体在文中多次出现，只输出一次规范名；别名统一到全名（少平→孙少平）。
4. 区分“煤矿”（ORG，工作单位）与“矿山”（LOC，地点）。
5. 输出 JSON 数组，每个元素包含 `name`、`type`、`evidence`；`evidence` 必须是原文子串。

示例输出：
```json
[
  {"name": "孙少平", "type": "PER", "evidence": "农民子弟孙少平"},
  {"name": "原西县高中", "type": "ORG", "evidence": "到原西县高中读书"},
  {"name": "1975年初", "type": "TIME", "evidence": "1975年初"}
]
```
